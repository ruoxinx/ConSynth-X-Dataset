## Notes / anomalies

- **Filter scope**: SSIM+LPIPS is applied only to rain (light & heavy).
  Snow / fog / night / night_weather pipelines do NOT filter; their
  `N_kept < N_input` reflects partial generation (subset), not rejection.
- **Paired rain_light = rain_heavy** (same N_kept across all sources):
  rain light/heavy share the same SSIM+LPIPS filter pass; the heavy
  variant is produced from the same kept subset.
- **soda_voc/snow_heavy = 1,000** and **soda_ktsh/snow_heavy = 1,000**:
  produced from the b2 small-batch pipeline (`_b2_inputs/snow_1000.arrow`).
- **fog × 3 ran on a 1k subset of CS test** (not 3,004), hence ~1,001 kept.
- **night_rain / night_snow = 3,004 / 3,004**: full CS test passed through
  Order-B without filtering.
- **DINO retention now covers all sources** — extended CSVs
  (cs_train_*, soda_voc_*, soda_ktsh_*) computed via
  `validation/extract_dino_ssim_extended.py` on Pitzer V100-32g.
