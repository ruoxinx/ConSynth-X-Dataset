# Dataset access and usage

The full ConSynth-X dataset is not redistributed through this repository or
through Hugging Face. The Hugging Face page is retained for project metadata,
documentation, citation, and future access instructions:

<https://huggingface.co/datasets/openconstruction/ConSynth-X>

This repository does not include dataset shards, source images, generated
outputs, or a public `load_dataset` download recipe. The project website
provides the high-level overview:

<https://ben11304.github.io/ConSynth-X/index.html>

For local regeneration using separately obtained upstream resources, see
[REPRODUCE.md](REPRODUCE.md). Upstream licensing and permission requirements
are summarized in [UPSTREAM_ATTRIBUTION.md](UPSTREAM_ATTRIBUTION.md).
